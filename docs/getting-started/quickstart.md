# Quick Start Guide

Generate your first AI image in minutes!

## 1. Start the Application

```bash
streamlit run app.py
```

## 2. Set Up Your API Key

1. Get your API key from [Replicate](https://replicate.com/account/api-tokens)
2. Enter it in the sidebar's password field

## 3. Create Your First Image

1. **Write Your Prompt**

   - Be descriptive and specific
   - Example: "A serene mountain landscape at sunset with a lake reflecting orange clouds"

2. **Choose Your Settings**

   - Aspect Ratio: Pick your preferred size (1:1, 16:9, 4:3, or 3:2)
   - Format: Select webp, png, or jpg
   - Quality: Set to 80-90 for good results
   - Safety: Keep at 4 for general use
   - Upsampling: Leave enabled for better quality

3. **Generate and Download**
   - Click "Generate Image"
   - Wait for the image to appear
   - Use the "Download" button to save it

## Example Prompts to Try

- "A cozy cafe interior with warm lighting and people chatting"
- "A futuristic cityscape with flying cars and neon lights"
- "An underwater scene with colorful coral reefs and tropical fish"
- "A peaceful garden with blooming flowers and butterflies"

## Tips for Great Results

1. **Be Specific**: Include details about style, mood, and lighting
2. **Use Adjectives**: Words like "serene", "vibrant", or "mystical" help guide the style
3. **Start Simple**: Begin with basic prompts, then add details
4. **Experiment**: Try different settings to find what works best
